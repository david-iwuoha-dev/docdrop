# Changelog

## 2.1.0

- Word documents are now centered in the DocDrop tab.
- Light appearance is now the default.
- The Open button now reads "Open New File".
- Search now works in Word documents.
- The typing cursor is solid black and easy to see.

## 2.0.0

- Word documents now open with their real page layout and can be edited and saved as `.docx` (SuperDoc).
- Spreadsheets can be edited: formula bar, typing in cells, insert and delete rows and columns, rename and add sheets, undo.
- Spreadsheet formatting (colours, fonts, borders, merged cells, column widths) is shown and kept when saving.
- PowerPoint support: view `.pptx`, `.ppt` and `.ppsx` files and play them as a slideshow.
- Save back to the original file, or Save as a new one.
- Search inside documents and across every sheet of a workbook.
- Zoom for spreadsheets, print or save as PDF, light and dark appearance.
- Recent files list in the DocDrop tab and the popup.
- "Created by Dave" footer.
- Built with Vite; GitHub Actions builds and publishes releases.
- Narrower permissions: only local file access instead of all websites.

## 1.1.0

- Popup with an on/off switch and a button to open the drop tab.

## 1.0.0

- First version: view `.docx` and spreadsheets in a tab, open downloads automatically.
